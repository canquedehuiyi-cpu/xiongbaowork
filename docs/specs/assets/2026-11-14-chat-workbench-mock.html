熊宝聊天工作台 · 设计稿 v2

方向不变：四个入口，聊天是主场，设置收起。这一版按大厂企业 IM 的质感重做，并把员工「拟人化」：每位员工有在线状态、此刻在做什么、工牌名片、所在部门和入职天数；对话里能看到「正在输入」、任务进度卡和需要你拍板的按钮。点左边图标切换，点聊天顶部的「名片」看员工资料。

手机宽度下只显示图标栏和列表，点进会话再全屏显示对话，和微信一样。

拟人化：员工像真同事

  • 头像右下角状态点：绿=空闲、橙=忙碌、灰=休息
  • 列表里显示他此刻在做什么，例如「正在跑测试 · 还剩约 3 分钟」
  • 名片：工牌号、部门、入职第几天、性格、擅长、带的技能
  • 对话里有「正在输入」、任务进度卡、需要你拍板的按钮
  • 工作台的「今日动态」像团队群公告：谁完成了什么

大厂质感怎么来的

  • 统一的圆角、细描边、柔和阴影，深浅主题都做
  • 一种主色（熊宝红到暖橙的渐变）只用在「我」的气泡、选中态和主按钮
  • 数字等宽、标题紧凑、留白克制
  • 通讯录按部门分组，像企业组织架构

收起来的设置

  • 模型、插件管理、审计、平台设置 → 工作台「管理」区，仅管理员可见
  • 员工配置（技能 / 插件 / 模型）→ 从名片的「配置」进入
  • 账户、套餐、外观、高级设置 → 「我」
