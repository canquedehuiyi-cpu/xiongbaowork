这台电脑主动连接你的熊宝服务器，供数字员工使用本机的文件、命令行和浏览器。本机不开放任何端口。

本地文件夹

添加到这里的文件夹，你的分身可以只读查看：能列出和读取其中的文件，不能修改、删除，也不能在里面运行命令。文件夹默认只读；只有在这里勾选「允许员工修改此文件夹中的文件」，并且项目在熊宝里也设为可写时，项目里的员工才能修改它。服务器只知道你起的名称，不知道文件夹在这台电脑上的位置。添加后，在熊宝的分身「信息来源」或项目里选择它。

    填写完整路径。不能添加设备端自己的数据目录，也不能添加包含它的文件夹。
    添加后不能直接更改权限：要更改，请移除后重新添加，并在熊宝的项目里重新选择这个文件夹。
