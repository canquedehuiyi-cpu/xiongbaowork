## 使用说明（商用风险提示，必读）

1. **免费素材**：清单内标注的许可类型仅供参考，使用前在源站确认当前许可条款；免费档的水印图、限次下载不可商用
2. **付费素材**：客户自行购买后获得商用授权，发来后我们整合——版权风险在购买环节已消除
3. **国内站 ≠ 免费**：摄图/千图/包图等的"免费下载"通常只限个人学习使用，商用必须开通授权；不确定时按"商用"流程处理（见 SKILL.md 素材搜集节）
4. **花瓣/站酷**：是灵感与跳转站，落地素材回到源站核实授权，别把页面缩略图当成品
5. **不内置素材**：本清单只提供站点链接，素材由客户自行获取，不在技能包中内置

## 八、海外 API 调用异常捕获协议（P461-P468）

> 只走海外备选路径（已配 Key 且网络可用）时适用。本技能为对话式设计助手，无内置脚本——以下为**调用行为协议**（宿主/工具层执行素材 API 时逐类归因），属于 SKILL.md 主协议 P407「素材获取失败」的明细码。
> **统一规则：任何异常都不反复重试、不阻塞流程**——立即按降级链切回国内站主流程，并向用户说明已切换。唯一例外：P464 限流（429）允许等待 ≥30s 重试 1 次。

| 错误码 | 异常类型 | 现象（位置+原因） | 处理（怎么修） |
|--------|---------|------------------|---------------|
| P461 | 未配置 Key | `PIXABAY_API_KEY` 等环境变量缺失/为空 | 不发起调用，直接走国内站主流程；确需海外补充再配 Key 后重试 |
| P462 | 连接超时 | 请求超 10s 无响应（应显式设置连接/读取 timeout ≤10s） | 视为失败直接降级国内源，不重试 |
| P463 | 网络不可达 | DNS 解析失败 / 连接被拒 / 证书错误（国内访问海外受限的典型症状） | 直接降级国内源，向用户说明「海外图库网络不可用，已切国内源」 |
| P464 | 限流 429 | HTTP 429 Too Many Requests | 等待 ≥30s 重试 1 次；仍 429 → 降级国内源 |
| P465 | HTTP 4xx 授权类 | 401/403（Key 失效/无权限） | 不重试（重试无意义），提示检查 Key，立即降级国内源 |
| P466 | HTTP 5xx 服务端异常 | 500/502/503/504 | 重试 1 次；仍失败 → 降级国内源 |
| P467 | 响应解析失败 / 空结果 | JSON 解析错误 / 返回 0 条匹配素材 | 重试 1 次或换 1 组关键词；仍无 → 换下一备选 API，最终切国内源并告知 |
| P468 | 下载失败 | 拿到 URL 后下载图片失败/超时/返回非图片内容 | 跳过该素材选下一张；连续 3 张失败 → 换关键词或切国内源 |

**调用前显式检查（每次调用先过一遍）**：
1. Key 是否已配置（缺 → P461，直接走国内源）
2. 参数完整性：显式 timeout（连接/读取各 ≤10s）、`lang=zh`、每页数量 ≤30
3. 发起调用后统一捕获异常并按上表归类（P462-P468），提示格式仍为「位置+原因+修法」中文三段式，绝不裸抛英文错误

**降级出口（任一失败都到这里）**：切国内站主流程 → 仍无结果走 SKILL.md 5.3 的替代方向（纯色几何 / 用户自己照片 / 换风格），不硬凑素材。
