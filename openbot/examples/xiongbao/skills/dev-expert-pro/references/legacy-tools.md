# 上游辅助工具：可选接入

本包保留编程专家 2.0.3 的 31 份 Python 辅助源码和 hooks/platform 模板，作为可选兼容资源。作者与许可见 [第三方说明](../THIRD_PARTY_NOTICES.md)。仅安装/加载本包不会注册 hooks 或写用户 IDE 配置。

## 工程探测与知识图谱

- [project_probe.py](../scripts/project_probe.py) 是编程大神的只读有限工程识别脚本，只给候选命令和线索，不执行项目代码。
- [build_graph.py](../scripts/build_graph.py) 是上游正则建图/查询工具，会在目标工程写 `.ai-memory/knowledge-graph`。先核对 `--root`、排除目录、源码范围和是否允许写入；只读审查时不要在目标仓库建图，可在隔离副本取证。
- 图谱不是语义分析或最新影响面的证明；别名导入、框架模板、动态调用和多语言覆盖有缺口。单实例使用，修改前/后通过真实引用搜索复核。`--no-rebuild` 不等于缓存有效，元数据和当前源码不一致时不能沿用旧结论。

## hooks/安装器

[hooks.json](../scripts/hooks.json) 原主模板包含 26 项注册，能否触发、是否阻断及输出送达由宿主实际事件协议决定。没有安装或触发证据时报告未启用；不得将文件存在叫作自动保护通过。

[init_deploy.py](../scripts/init_deploy.py) 的“部署”是 hook 配置接入，不是应用云部署。调用前读取目标计划；真实写入仅在用户明确要求该接入且目标/范围授权时进行。不要因主流程开始就运行 `--apply` 或修改全局配置。

保留源码的已知边界：部分检查只有正则提示；写前增量事件字段/完整文档重建不一致；`--events` 与写入配置的过滤口径不一致；可选复制模式没有完整携带间接依赖；验证配置不代表宿主真正触发；图谱并发锁与新鲜度检查不完善。故本版不推荐自动执行批量 hook 安装，也不声称这 26 项均有生产保障。

需要接入时，以具体宿主、事件样本、输入/输出 schema 和回滚配置进行针对性验证，补齐已发现缺陷再启用。目录扫描、备份、记忆归档都有本地副作用；原作者机器生成的 `hooks.installed.json` 已排除出发行包，不能直接使用旧注册路径。

其他 helper 的目录和源码会随包保留；[完整工具列表](legacy-tools-index.md)按需查看。任何 helper 结果仍按主入口区分通过、失败、未运行和不可用。
