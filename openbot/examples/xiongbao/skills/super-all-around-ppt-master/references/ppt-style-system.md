# PPT视觉风格体系（PPT Style System）

本文档为「超级全能PPT大师」阶段四与阶段七提供完整的视觉设计方法论。核心命题：**视觉是内容"被看见"的通道，而非装饰。** 极致精美的PPT，是配色、字体、版式、视觉锚点、留白五者和谐统一的结果。

---

## 一、八大视觉风格基调

| 风格 | 核心调性 | 代表色彩 | 适用场景 |
|------|----------|----------|----------|
| **专业商务** | 可信、稳健、专业 | 深蓝+灰+白 | 汇报、提案、述职、路演 |
| **科技未来** | 创新、前沿、酷炫 | 深蓝/黑+荧光蓝/紫 | 技术分享、产品发布、AI主题 |
| **极简高级** | 留白、克制、品质 | 黑白灰+单点强调色 | 高端品牌、个人简介、设计类 |
| **数据驱动** | 理性、精准、洞察 | 蓝+青+图表色系 | 数据分析、经营报告、行研 |
| **热情活力** | 积极、动感、年轻 | 橙/红+白 | 营销方案、活动策划、团队介绍 |
| **自然清新** | 舒缓、健康、生机 | 绿+白+木色 | 教育、健康、环保、生活方式 |
| **庄重政务** | 庄严、热烈、规范 | 红+金+白 | 党政汇报、党建、政务宣讲 |
| **优雅学术** | 严谨、克制、可信 | 深蓝/墨绿+白 | 学术答辩、科研汇报、教学课件 |

**风格选择原则**：
1. 根据类型与受众匹配（商业路演→专业商务/科技未来；党政→庄重政务；学术→优雅学术）
2. 色彩心理学：蓝=专业可信、红=热烈庄重、绿=生机健康、金=尊贵品质、紫=创新高端、橙=活力热情
3. 不确定时，默认「专业商务」——最稳妥、最通用

## 二、配色方案设计

### 2.1 四色法则（≤4种hex色）

一份PPT的主视觉配色不应超过4种颜色：

| 色彩角色 | 作用 | 占比 | 示例 |
|---------|------|------|------|
| **主色** | 品牌/主题色，定义整体调性 | 60% | #1A56DB（专业蓝） |
| **辅色** | 支撑主色，丰富层次 | 30% | #E8F0FE（浅蓝） |
| **强调色** | 聚焦焦点，突出重点 | 10% | #F5A623（金色强调） |
| **中性色** | 文字/背景，保证可读性 | 基底 | #333333（正文）/ #FFFFFF（背景） |

### 2.2 常用配色方案速查

| 方案名 | 主色 | 辅色 | 强调色 | 适用 |
|--------|------|------|--------|------|
| 科技蓝 | #1A56DB | #E8F0FE | #F5A623 | 商务/科技 |
| 商务深蓝 | #0F2B5B | #D6E2F5 | #E8A13A | 高端商务 |
| 活力橙 | #F97316 | #FEF3E2 | #1A56DB | 营销/活动 |
| 自然绿 | #16A34A | #E6F7EC | #F5A623 | 教育/健康 |
| 政务红 | #C8102E | #FBE9EC | #D4A017 | 党政/政务 |
| 学术蓝 | #1E3A5F | #E8EDF5 | #8C6D1F | 学术/答辩 |
| 高级黑白 | #1A1A1A | #F5F5F5 | #C8102E | 极简/高端 |
| 创新紫 | #6D28D9 | #F0E9FB | #F5A623 | 科技/创新 |

### 2.3 配色设计原则

1. **60-30-10法则**：主色60%、辅色30%、强调色10%
2. **强调色克制**：强调色只出现在焦点元素（关键数字/重点结论/行动按钮），而非满屏皆是
3. **对比度达标**：正文文字与背景对比度≥4.5:1，保证可读性
4. **色彩语义一致**：同一颜色在全篇表达同一含义（如蓝色=数据、金色=重点）

## 三、字体体系设计

### 3.1 双字体法则（≤2套字体家族）

一份PPT最多使用2套字体家族：

| 字体角色 | 用途 | 中文推荐 | 特征 |
|---------|------|---------|------|
| **标题字体** | 封面标题/页面标题/大数字 | 思源黑体 Bold / 微软雅黑 Bold / 阿里巴巴普惠体 | 庄重有力 |
| **正文字体** | 正文/注释/图表标签 | 思源黑体 Regular / 微软雅黑 / 苹方 | 清晰易读 |

### 3.2 字号层级

| 层级 | 用途 | 字号范围 | 备注 |
|------|------|---------|------|
| **L1 封面大标题** | 封面主标题 | 40-56px | 视觉冲击力 |
| **L2 页面标题** | 每页标题 | 28-36px | 清晰醒目 |
| **L3 正文** | 正文内容 | 14-18px | 易读舒适 |
| **L4 注释** | 脚注/来源 | 12px | 辅助信息 |

### 3.3 字体设计原则

1. **全篇统一**：标题统一用一套，正文统一用一套，不混用
2. **层级清晰**：通过字号+字重区分层级，而非通过多种字体
3. **可读性优先**：正文字号不小于14px，保证后排观众能看清

## 四、版式系统设计

### 4.1 画布尺寸

| 比例 | 尺寸 | 适用场景 |
|------|------|---------|
| **16:9** | 1280×720 / 1920×1080 | 标准演示（默认） |
| **4:3** | 1024×768 | 传统投影/打印 |
| **竖版** | 1080×1920 | 创意/移动端阅读 |

### 4.2 母版三区结构

```
┌─────────────────────────────────┐
│  A区：标题块（0-120px）          │  ← 页面标题
├─────────────────────────────────┤
│                                 │
│  B区：内容区（120-660px）        │  ← 核心内容/图表/图片
│                                 │
│                                 │
├─────────────────────────────────┤
│  C区：页脚条（660-720px）        │  ← 页码 NN/TOTAL + 装饰
└─────────────────────────────────┘
```

**母版设计原则**：
1. 三区齐全，全篇位置严格一致
2. 标题块右侧不塞装饰小图，保持简洁
3. 页脚含右下页码，便于观众定位

### 4.3 版式节奏

1. **避免连续相同版式**：连续两页相同版式会让观众产生"复制感"
2. **制造视觉重量变化**：最大元素面积比>1.5:1，或版式结构明显不同
3. **版式库参考**：
   - 标题+单大图（hero页）
   - 标题+三栏卡片（并列要点）
   - 标题+左图右文 / 左文右图（图文结合）
   - 标题+大数字+短句（数据强调）
   - 标题+时间线（过程展示）
   - 标题+表格/图表（数据呈现）

## 五、视觉锚点设计

### 5.1 锚点定义

视觉锚点是每页的"视觉焦点"——观众视线首先停留的地方。每页至少1个锚点。

| 锚点类型 | 判定标准 | 示例 |
|---------|---------|------|
| **大数字** | ≥48px的数字 | "3倍"成本降低 |
| **大图** | ≥40% B区面积 | 产品大图 |
| **大色块** | ≥44px的色块元素 | 强调色块 |
| **大图标** | ≥44px的图标 | 核心概念图标 |

### 5.2 锚点设计原则

1. **每页至少1个锚点**：没有锚点的页面 = 没有焦点的页面
2. **hero页锚点更大**：封面/章节页/结论页用≥40%主视觉或≥48px数字
3. **锚点服务于观点**：锚点必须是本页核心观点的视觉化，而非无关装饰
4. **全篇锚点有节奏**：不能每页都是大锚点（视觉噪音），也不能每页都无锚点（平淡无奇）

## 六、留白与密度基线

### 6.1 留白原则

1. **常规页留白≤35%**：留白过多显得空，过少显得挤
2. **hero页可高留白**：封面/章节页留白可达50%，营造呼吸感
3. **留白是设计元素**：刻意的留白能让内容"呼吸"，而非"浪费空间"

### 6.2 信息密度分级

| 页面角色 | 密度 | 特征 | 用途 |
|---------|------|------|------|
| **hero** | 低密度 | 大视觉+极简文字 | 封面/章节页/关键转折 |
| **supporting** | 中密度 | 要点+图表+适度文字 | 内容支撑页 |
| **transition** | 极低密度 | 章节标题+过渡语 | 章节过渡 |

## 七、数据可视化规范

### 7.1 图表类型选择

| 图表类型 | 适用场景 | 注意事项 |
|---------|---------|---------|
| **柱状图** | 对比（多类别比较） | 类别≤7个，否则改用条形图 |
| **条形图** | 排名对比 | 类别多时优先 |
| **折线图** | 趋势（时间序列） | 线数≤4条 |
| **饼图** | 占比（部分整体） | 切片≤6个，最重要放12点方向 |
| **漏斗图** | 转化（流程递减） | 层级≤5个 |
| **雷达图** | 能力（多维对比） | 维度≤8个 |

### 7.2 图表设计原则

1. **一图一结论**：每张图表只讲一个结论，结论写在标题里
2. **数据有标注**：关键数据点标注数值，而非让观众自己算
3. **颜色服务于重点**：强调色只标重点数据，其余用主色/中性色
4. **避免3D图表**：3D图表易造成视觉误差，2D更准确

## 八、视觉质量红绿灯

| 信号 | 状态 | 说明 |
|------|------|------|
| 配色≤4种且和谐 | ✅ 绿灯 | 专业统一 |
| 满屏五颜六色 | 🔴 红灯 | 视觉噪音 |
| 字体≤2套且统一 | ✅ 绿灯 | 清晰专业 |
| 字体混用杂乱 | 🔴 红灯 | 不够专业 |
| 每页有视觉锚点 | ✅ 绿灯 | 有焦点 |
| 页面无焦点 | 🔴 红灯 | 平淡无奇 |
| 版式有节奏变化 | ✅ 绿灯 | 不枯燥 |
| 连续相同版式 | 🔴 红灯 | 复制感强 |

## 九、与DESIGN.md的对应关系

阶段四产出的DESIGN.md应包含：
1. 风格基调（八选一及理由）
2. 配色方案（主色/辅色/强调色/中性色，含hex值）
3. 字体体系（标题字体+正文字体，含字号层级）
4. 版式系统（画布尺寸、母版三区、版式节奏）
5. 视觉锚点策略（每页锚点类型与分布）
6. 留白与密度基线（页面角色密度分级）
7. 页面色彩映射表（主色/辅色/强调色在每页的分配）

DESIGN.md是逐页制作的根本依据——所有页面必须严格遵循DESIGN.md的颜色、字体、版式规范，保持全篇视觉一致性。
