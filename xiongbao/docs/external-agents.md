# 招入外部员工：把电脑上的 Codex、Claude Code 招成员工

你电脑上已经装好的 Codex、Claude Code，可以直接招成熊宝员工。它们在你自己的电脑上、你指定的文件夹里干活；干活的过程实时出现在对话里；需要你点头的操作进「等你确认」，在电脑或手机网页上批准后才继续。

## 开始之前

- 电脑上装好设备端，并已和你的账号配对、显示「在线」。外部员工需要带这项功能的设备端（0.2.15 或更新）。
- 电脑上装有 Node.js（熊宝要用它下载「适配器」），以及你想招的 `codex` 或 `claude` 命令行程序。装好后重新打开终端，输入 `npx --version`、`codex --version`、`claude --version` 都能看到版本号。
- 在设备端窗口的「本地文件夹」里添加员工要干活的文件夹。
- 你不用在电脑上登录 Codex 或 Claude Code，也不用填密钥：员工用的模型由熊宝服务器提供。

## 招进来

1. 通讯录 →「招一位新同事」→ 页签「从我的电脑招」，选一台在线的电脑，点「重新查找」。
2. 找到的智能体会显示「已安装」等标签。点「招进来」。按钮是灰的，多半是电脑上没装 Node.js 或命令行程序。
3. 填名字、部门，选工作文件夹（员工只在这个文件夹里干活），保留默认的「哪些事要先问你」，确认。

招入后，它出现在通讯录、组织架构和消息列表里，带「外部员工 · Codex」这样的标记，名片上写着它在哪台电脑上。可以和它单聊、拉进群组、在群里 @ 它。

## 它怎么干活

- 对话里按顺序出现「进度」「改动」（改了哪些文件、加减多少行，可展开看）和命令的运行结果。
- 员工要做需要许可的事，比如推送代码、运行有风险的命令，会出现一张「请求许可」卡，同时在「等你确认」里多一条。默认规则下，推送、联网会先问你；改工作文件夹里的文件会直接做。
- 付款和下单、删除整个文件夹、对外发消息或邮件这三类事永远要你确认，规则改不了。
- 第一次启动要下载适配器，可能等一两分钟，期间显示「正在启动」。

## 在手机上批准

用手机浏览器打开熊宝网页并登录，进「我的 → 等你确认」（或在网址后面加 `/approvals`），点开那一条：能看到命令原文、员工、在哪台电脑上，底部有「批准」和「拒绝」。电脑上、手机上任何一处批了都算数。目前没有自动推送到手机的提醒，需要自己打开页面看。

## 电脑离线的时候

电脑关机或断网时，员工状态变灰，显示「离线 · N 件排队中」。派给它的活会排队，可以取消；电脑回来后按顺序继续。

## 运行位置：本机还是云电脑

- Codex 只能在你的电脑上跑。
- Claude Code 默认在熊宝的云电脑里跑，和你的电脑无关。想让它改你电脑上的文件夹，在它的员工设置里把「运行位置」切到「本机」，再选电脑和工作文件夹。名片上写「在 <电脑名> 上」说明是在本机。

## 常见问题

- **「招进来」是灰的：** 检查 Node.js、`codex` 或 `claude` 是否装好，装完要重新打开终端和设备端。
- **提示「这位员工的模型不支持 Codex 接入」一类：** 员工用的模型必须是 DeepSeek、OpenAI（Codex）或 Anthropic（Claude Code）这一类。员工没有单独绑定模型时用团队的默认模型，请管理员检查默认模型。
- **下载适配器很慢或失败：** 在电脑上设置环境变量 `XIONGBAO_NPM_REGISTRY`，指向可访问的 npm 镜像，然后彻底退出设备端再重新打开。
- **手机打不开审批页：** 手机要能访问熊宝服务器地址，请管理员确认服务器对外地址（`OPENBOT_PUBLIC_URL` 或 `BETTER_AUTH_URL`）已设置，端口已放行。

## 给管理员

- 对外地址必须是电脑和手机都能访问的；模型代理地址是它加 `/api/agent-model`。两者都没设时，外部员工会退回使用电脑上自己的登录。
- 模型代理默认开启，不要把 `XIONGBAO_AGENT_MODEL_PROXY` 设成 `off`。
- 没有「外部员工」的总开关。
