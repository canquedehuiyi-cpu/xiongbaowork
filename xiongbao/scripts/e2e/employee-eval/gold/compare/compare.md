# 五个开源项目对比

检索日期：2026-11-19

## Linux

Linux 内核以 GPL-2.0 发布，衍生作品分发时须同样开源。主线几乎每天都有提交，最近一次提交在 2026-11-18。GitHub 上约 200k star。

## VS Code

VS Code 的源码仓库采用 MIT 许可证，可以自由商用和修改。最近一次提交在 2026-11-19，发布节奏是每月一版。star 数约 180k。

## Rust

Rust 编译器和标准库按 MIT 或 Apache-2.0 双许可发布，使用者任选其一。最近一次提交在 2026-11-19。star 数约 105k。

## Kubernetes

Kubernetes 使用 Apache-2.0 许可证，附带专利授权，企业采用顾虑少。最近一次发布在 2026-11-12。star 数约 118k。

## PostgreSQL

PostgreSQL 使用自己的 PostgreSQL License，与 BSD/MIT 类似，非常宽松。GitHub 上的仓库是官方镜像，最近一次提交在 2026-11-18。star 数约 19k。

## 汇总

| 项目 | 许可证 | star 数 | 最近活跃日期 | 出处 |
| --- | --- | --- | --- | --- |
| Linux | GPL-2.0 | 200k | 2026-11-18 | https://github.com/torvalds/linux |
| VS Code | MIT | 180k | 2026-11-19 | https://github.com/microsoft/vscode |
| Rust | MIT / Apache-2.0 | 105k | 2026-11-19 | https://github.com/rust-lang/rust |
| Kubernetes | Apache-2.0 | 118k | 2026-11-12 | https://github.com/kubernetes/kubernetes |
| PostgreSQL | PostgreSQL License | 19k | 2026-11-18 | https://github.com/postgres/postgres |

这份样例只用来测判分脚本，star 数与日期不作为事实依据。
