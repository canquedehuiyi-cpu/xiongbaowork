# 数据处理：脏销售数据按「月 × 区域」汇总

本目录的 `sales.csv` 是从几个系统导出后拼起来的销售明细，约 1 万行，列为：`订单号,下单日期,区域,金额`。
数据比较脏，已知问题：

- **重复行**：同一个订单号可能出现多次（有的完全相同，有的写法不同）。同一订单号只算一次。
- **日期格式混杂**：`2026-03-05`、`2026/3/5`、`2026年3月5日`、`20260305`、`2026.03.05` 都有。
- **金额写法混杂**：有全角数字（如 `１２３.４５`）、千分位（如 `"1,234.50"`）、人民币符号（如 `¥88.00`）、两侧空格。
- **区域两侧可能有半角或全角空格**。区域只有四个：华东、华南、华北、西南。

## 交付物

在本目录写出 `summary.csv`（UTF-8，逗号分隔），按「月份 × 区域」汇总，**表头必须完全是**：

```
月份,区域,订单数,销售额
```

- `月份` 写成 `YYYY-MM`；`区域` 写去掉空格后的区域名；
- `订单数` 是去重后的订单个数（整数）；
- `销售额` 是去重后金额之和，保留两位小数，不带千分位和货币符号；
- 每个有订单的「月份 × 区域」一行，按月份升序、同月内按 华东、华南、华北、西南 排序。

可以写脚本处理，脚本留在本目录也可以。不要修改 `sales.csv`。
