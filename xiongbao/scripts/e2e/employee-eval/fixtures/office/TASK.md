# 多步办公：会议纪要 → 待办清单 + 邮件草稿

本目录的 `meeting-notes.md` 是一次项目周会的纪要。请：

1. 把纪要里**所有**明确分派给某个人的待办事项整理成 `actions.csv`（UTF-8，逗号分隔），表头必须是：

   ```
   负责人,截止日,事项
   ```

   - 每个待办一行；只收明确有负责人的事项，讨论过但没有分派的不要收。
   - `截止日` 一律写成 ISO 日期 `YYYY-MM-DD`（会议在 2026 年召开，纪要里的日期写法各不相同，请换算）。
   - `负责人` 写纪要里的中文名。

2. 为每一位负责人写一份邮件草稿，放在 `drafts/<负责人中文名>.md`（例如 `drafts/王芳.md`），
   草稿里要逐条提到这个人负责的每一件事和它的截止日，语气礼貌、简洁。
