# 对比：五个开源项目的许可证、活跃度和 star 数

请上网查这五个开源项目的官方仓库（GitHub）：

- `torvalds/linux`
- `microsoft/vscode`
- `rust-lang/rust`
- `kubernetes/kubernetes`
- `postgres/postgres`

每个项目要查清楚三件事：

- **许可证**：仓库声明的开源许可证（例如 MIT、Apache-2.0）；
- **活跃度**：最近一次提交（或最近一次发布）的日期，格式 `YYYY-MM-DD`；
- **star 数**：GitHub 上的 star 数（写成数字，例如 `123456` 或 `123k`）。

## 交付物

在本目录写一个 `compare.md`：

1. 每个项目一个小节（`## 项目名`），各写一段话（至少两三句），说清它的许可证、活跃度、star 数，以及你的看法（例如许可证对商用意味着什么）。
2. 最后一个小节 `## 汇总`，放一张 Markdown 表格，每个项目一行，至少包含这几列：项目、许可证、star 数、最近活跃日期、出处。出处写这个项目的 GitHub 地址（`https://github.com/<owner>/<repo>`）。
3. 文中写明检索日期，格式如「检索日期：2026-11-19」。

只写你实际查到的；查不到的写「未查到」并说明原因，不要编。
