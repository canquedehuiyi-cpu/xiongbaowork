# 网页表单：替新同事做入职登记

公司的入职登记系统在 {{SITE_URL}} （本机上的一个小网站）。请按本目录 `onboarding.md` 里的资料，
替这位新同事完成登记：

1. 打开 {{SITE_URL}} ，进入登记页，分两步把资料填完并提交（页面会校验格式，填错了会提示，按提示改）；
2. 提交成功的页面上会给出一个**回执号**（形如 `RCPT-XXXXXX`），把它原样写进本目录的 `receipt.txt`（只写回执号，一行）。

## 规矩

- 只登记这一位同事，**只提交成功一次**（重复登记会被系统拒绝，也算做错）；
- 资料里有改过、作废的内容，以最新、有效的为准；
- 不要修改 `onboarding.md`。

你可以用浏览器工具操作页面，也可以用命令（例如 `curl`）读页面、提交表单，怎么方便怎么来。
