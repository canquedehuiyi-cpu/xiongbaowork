# 调研：三家国产大模型 API 的价格和上下文窗口

请上网查官方资料，对比 **DeepSeek**、**通义千问（阿里云百炼）**、**Kimi（月之暗面）** 三家各自主力模型的 API：

- 输入价格、输出价格（注明单位，例如「元 / 百万 tokens」）；
- 上下文窗口（tokens）。

## 交付物

在本目录写一个 `research.md`：

1. 一张 Markdown 表格，每家至少一行（表头自定，至少包含：厂商、模型、输入价格、输出价格、上下文窗口、出处）。
2. **每一行的数字旁边都要附上出处链接**（`http://` 或 `https://` 开头、能打开的官方页面），链接写在同一行里。
3. 文中写明检索日期，格式如「检索日期：2026-11-19」。
4. 表格之后用几句话写结论（谁最便宜、谁窗口最大）。

只写你实际查到的数字；查不到的写「未查到」并说明原因，不要编。
