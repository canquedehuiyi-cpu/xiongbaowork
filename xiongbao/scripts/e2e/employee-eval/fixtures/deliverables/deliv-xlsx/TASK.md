# 交付：Excel 表格

请做一张办公用品采购预算表，保存为本目录下的 `budget.xlsx`（Excel 格式），放在第一个工作表里。

第 1 行表头必须是（四列，依次）：

```
项目,单价,数量,金额
```

接着三行数据，然后一行合计：

| 项目 | 单价 | 数量 | 金额 |
| --- | --- | --- | --- |
| 键盘 | 100 | 3 | 单价 × 数量 |
| 鼠标 | 50 | 4 | 单价 × 数量 |
| 显示器 | 800 | 2 | 单价 × 数量 |
| 合计 | （空） | （空） | 上面三项金额之和 |

要求：

- `金额` 列和合计必须是**公式**（例如 `=B2*C2`、`=SUM(D2:D4)`），不能只写算好的数；
- 文件里要存有公式算好的结果：只用 openpyxl 写公式的话文件里没有算好的值，别的程序打开会看到空白。
  请用能重新计算并保存的办法（例如 LibreOffice 无界面转换一次），保存后自己用 openpyxl 的 `data_only=True` 读一遍，
  确认金额是 300、200、1600，合计是 2100。

## 判分标准

1. 本目录下有 `budget.xlsx`，并且能被 openpyxl 打开；
2. 第一个工作表第 1 行表头是 `项目,单价,数量,金额`；
3. `金额` 列（D2 到 D5）是公式；
4. 用 `data_only=True` 读出的 D2、D3、D4、D5 分别是 300、200、1600、2100。
