# 交付：静态网页

请做一个「咖啡店今日菜单」的静态网页，放在本目录的 `site/` 下，入口是 `site/index.html`。

要求：

- 页面有标题、至少 4 样饮品的名字和价格；
- 样式写在单独的 `site/style.css` 里，用 `<link rel="stylesheet" href="style.css">` 引入；
- 页面里引用的本地文件（样式、脚本、图片）都要真的放在 `site/` 下，路径用相对路径，不要引用别的机器上的文件或需要联网才能拿到的资源；
- 页面上有一个文字为「推荐一杯」的 `<button>`，点击后页面文字要变（例如显示「今日推荐：某某饮品」）；脚本直接写在
  `index.html` 里的 `<script>` 中即可；
- 不需要服务器，直接用浏览器打开就能看。

做完后自己核对一遍：页面里每个 `src`、`href` 指向的本地文件是否都存在。

## 判分标准

1. 有 `site/index.html`，且有可见文字内容；
2. 页面里引用的相对路径资源（`src`、`href`，不含 `http(s)://`、`data:`、`#`、`mailto:` 开头的）都能在 `site/` 下找到；
3. （服务器侧另外检查：文件能下载和预览，页面能打开，点按钮后页面文字会变。）
