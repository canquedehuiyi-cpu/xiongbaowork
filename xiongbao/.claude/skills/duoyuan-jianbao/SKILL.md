# 多源简报

来源：今日日报日榜项目最近三十天技能（last30days-skill），多源简报技能。

## 适用场景

- 每天或者每周要一份行业动态简报，不想自己一个一个源去刷
- 要把多个来源的信息汇总成一份可读的简报，分发给群组或者用户
- 长期跟踪一个话题，需要固定来源、固定分类、固定格式

## 规则

- 固定来源清单：订阅源、代码仓库动态、社交平台、视频、播客，不临时加源
- 每天定时自动跑一次，生成后先内部过一遍再发布，不直接推送
- 流程固定五步：搜集、分类、筛选、简报、发布，不跳步
- 分类固定六类：人工智能研究、技术产品、商业投资、政策监管、文化艺术、生活方式
- 每个要点一百到三百字，带来源链接，只留高信号的，低信号的直接丢掉
- 简报里的时间、数字、链接以来源为准，不凭记忆补写
- 来源清单可以按用户需求调整，调整后要写进清单，下次按新清单跑
