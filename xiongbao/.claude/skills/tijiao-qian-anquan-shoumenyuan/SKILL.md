# 提交前安全守门员

## 适用场景

员工执行对外发布、提交等敏感动作之前必须使用。不是让员工更会干活，而是让它在干危险动作之前先被一道自动检查拦住。

## 使用方法

1. 敏感动作之前先跑自动检查，检查按严重程度排序，每条都带触发的文件和行号。
2. 发现严重风险就拦住动作，并告诉员工具体是哪条规则、怎么修，而不是等用户事后发现。
3. 规则包超过 60 天要提醒更新，过期规则不许默默继续用。
4. 检查结论要写清能证明什么、不能证明什么，不承诺包过。
5. 安装验证时要真的喂一条提交命令给检查，确认它能拦住才算装好。

## 注意事项

本技能只学守门员机制，不抄上游的 124 条应用上架规则，熊宝不做应用上架。检查结论只进审批，不自动执行。
