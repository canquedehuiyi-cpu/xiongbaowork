# 智能画图

## 适用场景

用户说一句话要一张图的时候使用，例如画应用架构图、按影响和投入排项目的象限图、带令牌刷新的时序图。一次只画一张图，批量出图要在外面再包一层任务编排。

## 使用方法

1. 先问清要画什么图、图里有哪些节点、节点之间是什么关系。
2. 先说清计划，再写出一个自包含的网页文件，里面是矢量图，双击就能打开。
3. 布局按四格网格排布，检查重叠和裁剪，检查对比度。
4. 可以从已有绘图工具的图导入重画，也可以导出图片格式。

## 品牌适配

先看用户的网站或者品牌材料，抽取品牌配色和字体，之后所有图都按这个品牌出。没有品牌材料时用默认风格，不编造品牌色。

## 注意事项

本技能只负责画图，不负责核对图里业务内容的对错，业务内容要由员工另外核对。改图也是说一句话，不要手动拖动。
