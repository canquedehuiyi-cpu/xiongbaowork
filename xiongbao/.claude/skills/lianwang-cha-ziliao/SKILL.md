# 联网查资料

来源：今日日报日榜项目火爬虫（firecrawl），本地部署的联网检索工具。

## 适用场景

- 用户问一个需要最新信息的问题，模型训练数据里没有，或者可能已经过时
- 员工要查文档、查价格、查状态，先拿到可靠来源再动手
- 需要给出引用链接和出处，不能只给一句话结论

## 规则

- 优先走本地版：单二进制本地部署，不依赖云端，敏感信息不出本地
- 云端回落默认关掉，敏感信息一律走本地版，不经过第三方云服务
- 查到结果先给出来源链接，再给结论，链接和结论一一对应
- 查不到就写没查到，不编链接，不编数据，不凑数
- 免费额度有限，先用本地版，云端只在本地版确实查不到时再考虑
- 检索结果只做参考，涉及下单、提交、对外发布这类敏感动作，仍要走审批流程
