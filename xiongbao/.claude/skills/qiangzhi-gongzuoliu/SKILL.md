# 强制工作流

来源：今日日报日榜项目超级能力（superpowers），强制工作流技能包。

## 适用场景

- 任务超过一步，需要先想清楚再动手，不能边做边想
- 大任务要拆给多个并行员工去做，需要统一的拆法和交接格式
- 任务做完要有人检查，检查通过才算完成，不能自己说完成

## 规则

- 构思阶段先问清目标和约束，再动手，不带着模糊需求开工
- 设计阶段出可执行的拆解，每一步写清要做什么、做到什么程度算完成
- 任务拆完再分给并行员工，分工写清楚，交接格式统一
- 每步执行完由检查员逐项核对，核对不过就打回重做，不直接放行
- 写代码以外的动作同样适用：调应用、查资料、回消息，都按同一套流程走
- 流程是强制的，不是建议，跳过构思或者评审步骤的任务不算完成
