# 迭代自循环

来源：今日日报日榜项目光标插件集（cursor/plugins）中的自迭代循环机制。

## 适用场景

- 任务一次没做完，需要反复改、反复验，直到通过
- 任务卡住了，需要换个思路再试，而不是在原地反复报同样的错
- 需要把多轮尝试的过程留下来，方便事后复盘哪一轮改对了

## 规则

- 每轮只改一处，改完立即验证，不一次改多处再验
- 每轮写清改了什么、验证结果如何，过程要留痕
- 验证不过就复盘失败原因，再定下一轮改什么，不重复试已经失败的改法
- 达到轮数上限，或者连续两轮没有进展，就停下并汇报，不无限循环
- 循环结束时给一份小结：改了几轮、哪一轮通过了、还剩什么问题
- 需要人确认的动作不放进循环里，循环只处理可以自动验证的步骤
