# 多智能体任务编排

## 适用场景

大任务要分给多个员工并行去做的时候使用，例如多员工群聊编排、任务拆解、并行执行再汇总。

## 使用方法

1. 先由规划员把大任务拆开，写清每个子任务的目标、输入、输出、验证方法。
2. 每个子任务派一个员工去做，做完逐项核对，不要等最后统一核对。
3. 再由检查员按重要性分组核对，核心改动在前、影响其次、收尾工作最后。
4. 交接要结构化，写清做了什么、没做什么、下一步是什么，不要只留一句话。

## 注意事项

本技能是编排方法，不是具体业务技能。任务拆得太碎会增加交接成本，拆得太粗会跑偏，拆到每个子任务能在较短时间内做完为宜。
