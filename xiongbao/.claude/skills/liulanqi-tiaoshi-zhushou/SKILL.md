# 浏览器调试助手

## 适用场景

员工需要操作真实浏览器的时候使用，例如看网络请求、截图、读控制台消息、查性能、查内存泄漏、查登录和会话问题。

## 使用方法

1. 先确认用户授权了哪个浏览器页面，员工只能看到授权范围内的页面。
2. 用浏览器调试协议操作浏览器，自动等待操作结果，不要靠猜测等待时间。
3. 性能分析时可以录制轨迹并给出可操作的建议，必要时结合真实用户体验数据。
4. 调试分七类：调试和自动化、命令行写脚本、无障碍审计、会话调试、最大内容绘制优化、内存泄漏、连接问题排查。

## 注意事项

浏览器里的内容会暴露给调用方，敏感信息不要进，例如银行、邮箱页面内容不要喂给模型。性能工具会调外部接口，不需要时可以关掉。用量统计默认开启，不需要时可以关掉。官方只支持谷歌浏览器，其他浏览器不保证兼容。
