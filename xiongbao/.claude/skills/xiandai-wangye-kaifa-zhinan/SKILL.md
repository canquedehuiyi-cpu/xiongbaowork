# 现代网页开发指南

## 适用场景

员工写前端代码、生成页面之前使用。模型训练数据有截止日期，容易默认用老写法，本技能提供一份持续更新的专家指南。

## 使用方法

1. 写前端之前先查指南，确认有没有原生高性能方案，例如容器查询、弹出层、锚点定位、视图过渡等。
2. 有原生方案就用原生方案，不要写臃肿的脚本去模拟。
3. 用新特性时配合理的降级方案，不要一味追新。
4. 可以扫描代码库里的过时写法，列出清单再逐项改。

## 注意事项

指南按篇幅裁剪过，只留模型还不知道的内容，内容由多家浏览器厂商和文档团队背书，可以放心用。注意不要装错包，使用时装指南包，不要装源码仓。
