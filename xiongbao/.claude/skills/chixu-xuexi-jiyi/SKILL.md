# 持续学习记忆

## 适用场景

员工每天读对话学习惯、整理成记忆的时候使用。下次遇到同类任务，先查记忆再动手。

## 使用方法

1. 只留高信号的要点，低信号的、一次性的、已经过时的不要留。
2. 增量更新记忆，新增要点要写清来源和时间，不要整段重写。
3. 记忆要分主题存放，方便按主题查找，不要堆在一个文件里。
4. 定期清理记忆，删掉已经失效的、互相矛盾的要点，清理时要留记录。

## 注意事项

记忆是员工的，不是用户的隐私外泄通道。内部资料和公开信息要分开存放，不要混在一起。记忆更新只增量改动，不要因为一次对话就推翻已有结论。
