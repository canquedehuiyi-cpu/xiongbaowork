# 表格文档助手

## 适用场景

用户说一句话要改表格的时候使用，例如把报价单的数量改成 4，公式自动重算。员工读写表格文档、给用户出报表时也使用。

## 使用方法

1. 直接调表格接口改单元格、跑公式，不要模拟鼠标点界面。
2. 编辑器和应用操作同一份工作簿，公式改了自动重算。
3. 改动和撤销要成组执行，例如在筛选区域里插一行，要同时改基础内容和筛选范围，撤销时两者都要恢复。
4. 先在熊宝里试点一个改表格的场景，验证后再铺开。
