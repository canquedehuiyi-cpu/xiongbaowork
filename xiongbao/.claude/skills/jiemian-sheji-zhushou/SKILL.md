# 界面设计助手

## 适用场景

新页面试点时使用，例如新员工卡片、审批箱等新页面。已有页面不全量替换。

## 使用方法

1. 先确认新页面要用哪些组件，查组件清单和用法，不要靠猜。
2. 主题就是一组样式变量覆盖，改几个变量就能换成自己的品牌，不用再包一层。
3. 组件不够深的时候可以把整个组件源码导出到自己项目里持有。
4. 写界面之前先把使用指南写进员工手册，让人和智能体按同一套规范来写。

## 注意事项

本技能处于试点状态，要求较新的前端框架版本，接口可能还会变。试点验证有效再扩大范围，不要一上来就全量替换已有前端。
