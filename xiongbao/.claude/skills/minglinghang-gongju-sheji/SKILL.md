# 命令行工具设计

## 适用场景

员工要给本地应用设计命令行工具，或者给智能体用的工具定规范的时候使用。

## 使用方法

1. 工具要有清晰的命名参数，不要接受原始命令字符串，避免注入。
2. 每个操作都要可重复执行，重复跑同一条命令结果一致。
3. 危险操作要有预览模式，先看要改什么，再决定执不执行。
4. 报错要写清原因和下一步，不要只报失败。
5. 工具的描述和实现不要两处手写，描述要从实现自动生成，定期校验有没有漂移。

## 注意事项

自动生成的命令行工具涉及本地命令执行，必须做路径校验，执行前要过审批箱，不能绕过审批。
